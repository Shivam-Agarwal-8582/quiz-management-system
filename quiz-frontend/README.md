# QuizMaster Frontend

React 19 + Vite frontend for the QuizMaster quiz platform.

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint     # ESLint
npm run build    # production build → dist/
```

The backend is expected at `http://localhost:8080/api` — override with `VITE_API_URL` in a `.env` file (see `.env.example`).
